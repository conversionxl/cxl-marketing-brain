# raw/

The inbox. Dump anything here without organizing it: meeting notes, call transcripts, voice memo text, pasted emails, screenshots of whiteboards, half-formed ideas.

Customer data, research, strategy docs, performance reports, and copy samples can land here too. `/ingest` and each Marketing Brain exercise move them into `raw/voc/`, `raw/strategy/`, `raw/performance/`, or `raw/brand/`, where the exercises read them.

Run `/ingest` to process it. Claude reads everything, proposes where each piece belongs, and files it after you confirm. Nothing here is expected to be tidy.
