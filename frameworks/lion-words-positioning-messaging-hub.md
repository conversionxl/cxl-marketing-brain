# Positioning and messaging hub

> **Credit:** Diane Wiredu, [Lion Words](https://www.lionwords.com/). This is her Lite Positioning & Messaging Hub, with three items added from her Messaging House template: the big idea, customer words, and the differentiation snapshot. Taught in the CXL AI Native Marketer cohort, Marketing Brain workshop.

The hub is the single page every other piece of copy draws from. Part 1 decides where you stand. Part 2 decides what you say about it. Exercise 2 fills it into [[wiki/brand/positioning-messaging|positioning-messaging]].

## Before you start: the core four

If a prospect can't answer these four about you, no amount of voice work helps. The hub answers each one in detail.

| Question | Answered by |
|---|---|
| **Clarity:** what is it? | Market, product / solution |
| **Relevance:** who is it for? | Customer (starts from [[wiki/brand/icp]]) |
| **Value:** why should I care? | Problems we solve, value we enable |
| **Advantage:** what sets you apart? | Competitive alternatives, unique attributes, differentiation snapshot |

## Part 1: Positioning

### Customer
- **Buying champion (persona):** the person who finds you, argues for you internally, and owns the result.
- **Company types:** the kinds of company that buy, and the ones that don't.
- **Primary use case:** the main job they hire you for.
- **Buying context:** what is happening when they go looking: the trigger, the deadline, who else is involved.

Start this section from [[wiki/brand/icp|icp]]. Do not re-derive the buyer here.

### Market
- **Market category:** where you compete, in words a buyer would type into a search bar.

### Competitive alternatives
What buyers do today instead of buying you. Include doing nothing, doing it by hand, hiring someone, and direct competitors.

| | Approach | Limitations |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

### Problems we solve
- **Core problem summary:** one or two sentences.
- **Sub-problems 1 to 3:** the parts of the core problem: what is broken.
- **Struggles 1 to 3:** what living with the problem feels like day to day, in the customer's words where you have them.

### Unique attributes
- **Differentiation:** what you have or do that the alternatives above don't. Each attribute must be true, provable, and something a buyer cares about.

## Part 2: Messaging

### Big idea *(from the Messaging House)*
- **Owned key message:** the one message you want to own in your category. The anchor for everything else.
- **What it means:** the key message unpacked in two or three plain sentences.
- **Customer validation:** evidence that customers already think or say this. A quote from `raw/voc/`, or blank.

### Value we enable
- **Core value proposition:** the outcome, in one sentence.
- **Value themes 1 to 3:** the main kinds of value (time, money, risk, status, capability), each with one line.

### Product / solution
Three messaging pillars. Each pillar is one reason to believe the core value proposition.

|---|---|---|---|
| **Capability** | | | |
| **Benefit** | | | |
| **Supporting features** | | | |

Customer words are verbatim quotes from `raw/voc/`, with the source file. Never paraphrased, never invented. A pillar with no customer words or no proof stays blank there: that gap is the finding.

### Differentiation snapshot *(from the Messaging House)*
- **Core summary:** one sentence on why you and not the alternatives.
- **Up to four differentiators**, each set against a named alternative from Part 1:

| Differentiator | Versus (named alternative) | Why it matters to the buyer |
|---|---|---|
| | | |

The test: could a competitor copy this row onto their own page and have it still be true? Then it is not a differentiator.
